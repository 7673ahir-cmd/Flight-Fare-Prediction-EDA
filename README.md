# ✈️ Flight Price Prediction

Predicting airline ticket prices using Exploratory Data Analysis (EDA), feature engineering, and machine learning.

---

## 📊 Project Overview
This project analyzes flight data to understand factors affecting ticket prices and builds a machine learning model to predict fares.  
Key steps include:
- Data cleaning and preprocessing
- Feature engineering (date, time, stops, duration)
- Encoding categorical variables
- Model training and evaluation

---

## ⚙️ Tech Stack
- **Python** (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn)
- **Jupyter Notebook** for analysis
- **Machine Learning Models**: Linear Regression, Random Forest, XGBoost
